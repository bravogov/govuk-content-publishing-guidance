Corporate information pages explain different things about how a government organisation works, such as its:

* governance
* complaints procedure
* accessible documents policy
* energy use

When you publish a corporate information page, a link to it will appear automatically in the 'Corporate information' section on your organisation and 'About us' pages.

## Confirm the content with the responsible organisation

Use the guidance for the selected corporate information type to identify what the page needs to cover. Do not publish every type of page simply because it appears in the list below.

Before creating or reviewing a page, check the organisation's current responsibilities and the records that establish the facts, for example its legislation, approved decisions, governance documents, operational procedures, appointments and contact arrangements. The responsible organisation supplies the substantive information; the content editor checks that the page follows GOV.UH publishing standards. Use the appropriate source for the particular page, not an outdated copy of another organisation's text.

If the relevant decision, office-holder, procedure or receiving service is not confirmed, do not present it as established. Keep historical editions and any documents issued by another institution under their proper owner.

## Keep corporate information up to date

Review a page when the underlying arrangements change, including changes to legal responsibilities, boards, contacts, complaints procedures, published information or personal data handling. Do not leave an identified factual error until the scheduled review date.

For an existing corporate information page:

1. Check its last published edition, source records, owner and any review date in Whitehall Publisher.
2. Confirm the facts with the responsible organisation and check the relevant corporate information guidance below.
3. If the page remains accurate, record the check and update the review date where the native editor supports it.
4. If the page needs changing, create an edition, explain the reason in its internal history, check the preview and use the normal second-eyes and authorised publishing route.
5. Check the published page, links, accessibility, related organisation pages and contact or service routes after release.

Use [Manage existing GOV.UH content](/writing-to-gov-uk-standards/plan-manage-content/manage-existing-govuk-content/) to find and audit existing pages. A scheduled review is a reminder to check the page, not permission to amend the underlying decision or to republish content without the required review.

## Add or edit a corporate information page

To add a page:

1. {% include 'reusable-content/whitehall-publisher.md' %}

2. Select the 'More' tab.
3. Select 'Organisations'.
4. Search for the organisation and select 'View' next to its name. 
5. Select the 'Pages' tab.
6. Select 'Create a new corporate information page' to add a new page.
7. Select the type of page and fill in the summary and body.
8. Select 'Save and go to document summary’. 
9. Under the ‘Topic taxonomy tags’ heading, select ‘Add tags’. Tick the boxes next to each topic that applies and select 'Save'.
10. When you're happy with the content, select 'Submit for 2nd eyes' so another editor can review the page and publish.

To edit a page:

1. On your organisation page, select the 'Pages' tab.
2. Select 'View' on the page you want to edit.
3. Edit the summary or body text as required.
4. When you're happy with the content, select 'Save and go to document summary'.
5. Select 'Submit for 2nd eyes' so another editor can review the page and publish.

## Add or edit attachments to a corporate information page

Make sure you correctly [format attachments](https://guidance.publishing.service.gov.uk/formatting-content/attachments/) before you upload them.

Select the ‘Attachments’ tab at the top of the page. You can add, edit or delete attachments from here.

You can upload up to 500MB of attachments at one time. If you want to upload a single attachment larger than 500MB, [report a technical fault](https://signon.publishing.service.gov.uk/users/sign_in) to get support.
